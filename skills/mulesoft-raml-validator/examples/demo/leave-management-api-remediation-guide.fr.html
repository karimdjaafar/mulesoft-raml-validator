Prochaines étapes

  1. Relire le RAML corrigé (examples/demo/leave-management-api-best-practices.raml). En particulier les 6 transformations signalées ci-dessus.
  2. Remplacer les valeurs provisoires. Les descriptions générées (DOC-001/002/003), les URI d'authentification (SEC-001) et les exemples (SPEC-001/002) respectent les règles mais n'ont aucun sens métier.
  3. Vérifier les noms de scopes si SEC-002 a été appliquée : le générateur les déduit du chemin ; ils doivent exister dans votre fournisseur d'identité.
  4. Refaire l'audit du RAML corrigé pour confirmer 100/100 GO. Tout autre résultat est un bug à signaler.
  5. Enregistrer les deux fichiers ensemble — le RAML corrigé et ce guide, qui sert de journal des modifications.
